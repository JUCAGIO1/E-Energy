Arquitetura de Segurança Zero Trust

Desenvolvido com padrões industriais contra ciberataques, vazamentos e adulteração de dados.

HMAC-SHA256 & eFuse

Chave secreta de 256 bits gravada no silício do microcontrolador. Cada medição enviada contém assinatura digital não forjável.

Anti-DDoS & RateLimiter

Sistema de limitação de requisições por IP no backend Express, bloqueando robôs e ataques de negação de serviço ao vivo.

Proteção Anti-Injeção NoSQL

Filtros de sanitização de pacotes removendo operadores maliciosos para garantir total integridade no banco de dados MongoDB Atlas.

Projeto de Conclusão de Curso (TCC)

O E-Energy nasceu como um projeto de conclusão de curso com a visão de revolucionar a eficiência energética em residências e pequenos comércios. Combinando Engenharia de Hardware, Internet das Coisas (IoT), Desenvolvimento Mobile e Segurança da Informação, o projeto está preparado para evolução em Startup de tecnologia.
